# Tgldash

Веб-приложение для просмотра маршрутов городского транспорта Тольятти на карте.

## Данные

Исходные данные — [Реестр муниципальных маршрутов](https://tgl.ru/structure/department/reestr-municipalnyh-marshrutov-regulyarnyh-perevozok/) городского округа Тольятти, опубликованный на официальном портале города.  
Распространяются по лицензии [Creative Commons Attribution 4.0 (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).

Автор не имеет отношения к администрации города Тольятти. Приложение является независимым и создано в информационных целях.

## Установка и запуск

```bash
# Установка не требуется
node server.js
```

Открой `http://localhost:8080`.

### Парсинг остановок

Извлекает уникальные названия остановок из таблицы и сохраняет в `stops.csv`:

```bash
node parse_stops.js
```

## Файлы

| Файл | Назначение |
|------|-----------|
| `server.js` | HTTP-сервер, читает `.env`, отдаёт конфиг и статику |
| `index.html` | Клиентское SPA (список маршрутов + Яндекс Карты) |
| `parse_stops.js` | Скрипт для извлечения остановок в CSV |
| `geo.json` | Координаты остановок (заполняется вручную) |
| `.env` | API-ключ Яндекс.Карт и ссылка на Google Sheets |
| `stops.csv` | Сгенерированный список уникальных остановок |
